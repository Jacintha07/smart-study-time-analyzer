# Smart Study Time Analyzer

A Python project that analyzes study hours per subject.

## What it does
- Stores subject and study-hour data
- Calculates total study time
- Shows which subject gets the most and the least time

## Concepts used
Python lists, tuples, and loops

## How to run
Open `Smart Study Time Analyzer.ipynb` in Jupyter Notebook or Google Colab and run all cells.
